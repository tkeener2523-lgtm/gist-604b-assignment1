## Repository 1

**Repository Name:** BlenderGIS
**Link:**https://github.com/domlysz/BlenderGIS

### Purpose
What does this project do?
This project allows for the importing of the most common GIS files into the 3D modeling software of Blender.
### Repository Structure
What folders or files stand out?
The folders of the project are structured similar to other projects but the license folder stands out. It is licensed with GNU General Public License v3.0.
### Documentation
How helpful is the README?
The README is very helpful giving a thoughtful background to the repository while also adding links for more information on the tools included with this project.
### Activity
Is the repository actively maintained?
It appears that this project is somewhat maintained. There have been multiple commits in the past but the last commit was 10 months ago.
### Key Observation
One thing this project does well.
I think this repository does a good job showing the workflow of this repository. There is a graphic that shows the workflow of different data sources and connections. Overall, it does a good job at also showing how the project can be implemented with Blender.

## Repository 2
**Repository Name:**  RustGIS
**Link:**  https://github.com/opengeos/RustGIS

### Purpose
What does this project do?
This project creates an open source GIS platform through the use of coding language RUST. It is usable on Windows, Mac, and Linux with projects being written on the native machine.
### Repository Structure
What folders or files stand out?
The file that stands out is the ROADMAP.md file. It gives a roadmap for coming features to the application, as well as, already implemented features. It gives user the ability to see what future releases will involve. 
### Documentation
How helpful is the README?
The README was very helpful and full of information about the application. It showed analysis types, supported formats, and a Quickstart guide.
### Activity
Is the repository actively maintained?
The repository is actively maintained with edits occurring almost daily.
### Key Observation
One thing this project does well.
This project does a very good job at showing the tools and resources available with this program.
